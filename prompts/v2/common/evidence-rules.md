# Evidence and uncertainty rules

- Use only the supplied source evidence.
- Preserve original labels and readable source values.
- Include the required page or source-location reference for extracted facts.
- Use the stage's explicit null, unknown, uncertain, unreadable, unable-to-check or inconclusive outcome when evidence is insufficient.
- A structurally valid output is not proof that its content is true.
- Give only concise, inspectable reasons requested by the schema; do not provide hidden chain-of-thought.
